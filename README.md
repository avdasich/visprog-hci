
# Visual Programming & HCI

Учебный проект на Kotlin, в котором собраны практические работы по Android и программированию.

## Что есть в проекте

### Random Walk

Консольная программа, которая моделирует движение людей в двумерном пространстве.

Используются классы `Human` и `Driver`, наследование, интерфейс `Movable` и потоки. Люди движутся в случайных направлениях, а водитель движется прямолинейно.

Исходники: `app/src/main/java/Movable/`

### Android-приложение

В приложении реализованы несколько отдельных экранов:

- Калькулятор с основными арифметическими операциями.
- Медиаплеер с локальными аудиофайлами.
- Получение координат устройства.
- Обмен сообщениями через ZeroMQ.
- Отправка GPS-координат на сервер через ZeroMQ.

Все разделы доступны из главного меню.

## Используемые технологии

- Kotlin
- Android SDK
- Gradle
- JeroMQ (ZeroMQ)
- C++ (отдельный серверный проект)

## Структура

- `app/` — Android-приложение и исходники работ.
- `gradle/` — настройки Gradle.
- `server/visual/` — подключённый Git-сабмодуль с отдельным проектом на C++.

## Сборка

Клонировать проект вместе с сабмодулями:

```bash
git clone --recurse-submodules https://github.com/avdasich/visprog-hci.git
cd visprog-hci
```

Открыть проект в Android Studio и выполнить синхронизацию Gradle.

Либо собрать Debug APK из терминала:

```bash
./gradlew :app:assembleDebug
```

Для работы GPS-функций необходимы разрешения на геолокацию.

Функциям ZeroMQ нужен запущенный сервер. Адрес сервера вводится в приложении, используется TCP-порт 2222.

## Серверная часть

Проект на C++ находится в отдельном репозитории:

[AndroidBackend](https://github.com/avdasich/visual)

Он подключён через Git-сабмодуль в `server/visual/`.
